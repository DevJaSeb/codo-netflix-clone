# 🎬 Netflix Clone

A responsive movie and TV series web application inspired by the Netflix interface.

The project was developed to practice modern frontend development with React, API consumption, state management and reusable components.

## ✨ Features

* 🎬 Browse movies and TV series
* 🔎 Retrieve movie and series information through an external API
* 🖼️ Display posters and media information
* 📱 Responsive interface
* 🧭 Dynamic navigation
* ⚛️ React component-based architecture
* 🗃️ Global state management with Redux
* 🔄 Redux Toolkit for state management
* 🚀 Deployment with Vercel

## 🌐 API

The application consumes the **IMDb API** to retrieve movie and TV series information.

The API is used to dynamically obtain media data instead of relying exclusively on static content.

## 🧠 State Management

Redux and Redux Toolkit were used to manage application state and keep data accessible across the React application.

This project provided practical experience with:

* Global state management.
* Redux Toolkit.
* React integration with Redux.
* Managing API-related data.

## 🚀 Getting Started

### Prerequisites

* Node.js
* npm
* Git

### Clone the repository

```bash
git clone https://github.com/DevJaSeb/codo-netflix-clone.git
cd codo-netflix-clone
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.
